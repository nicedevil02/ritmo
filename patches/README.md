# پچ تغییرات دورهای ۱ تا ۵ — فایل‌های اصلاح‌شده

این پوشه حاوی تغییرات ۳۴ فایل موجود ماژول ورزش تکمیلی است (اصلاحات دور ۱ تا ۵: لاگ‌کردن خطاها، tooltip و دسترس‌پذیری، محافظ خروج، بازچینی ناوبری تب حرکت، ثبت جلسهٔ قدرتی در تاریخچهٔ واحد، و آنبوردینگ چندورزشی).

فایل به‌صورت gzip+base64 و در ۳ قطعه ذخیره شده تا در انتقال هیچ نویسه‌ای آسیب نبیند.

## اعمال

از ریشهٔ مخزن، روی همین برنچ:

```bash
cat patches/ux-rounds-1-5-modified.patch.gz.b64.part-* | base64 -d | gunzip > /tmp/ux.patch
git apply /tmp/ux.patch
```

پس از اعمال، این ۳ قطعه و همین README را می‌توانید حذف کنید.
